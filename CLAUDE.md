# ximi4ka-shop — инструкции для сессий

## SEO: работа адресуется на `docs/seo/WORKFLOW.md`

Любая задача про SEO — позиции, индексация, title и description, JSON-LD и микроразметка, sitemap, robots.txt, llms.txt,
фиды (YML, Turbo, RSS), крошки, статьи и тексты товаров, Яндекс.Метрика и цели, семантическое ядро, переключение апекса
`ximi4ka.ru` с Tilda, серверные импорты SEO-данных — выполняется строго по **`docs/seo/WORKFLOW.md`**. Прочитай его
целиком до первой правки; план и серверные команды лежат рядом (`docs/seo/seo-plan-2026-q4.md`, `deploy/SEO-LAUNCH.md`).

## Выкатка

Мёрж в `main` = выкатка в прод (автодеплой). Мёржить, ходить на прод-сервер и в прод-БД — только по явной команде владельца
в чате. Исключение: мелкие правки, не затрагивающие функционал, вносятся и мёржатся без согласования — строгие критерии
в разделе 1.1 `docs/seo/WORKFLOW.md`; сомневаешься — не мелкая. Подробности и стоп-правила — в разделе 1 того же файла;
устройство деплоя — в `deploy/README.md`.

## Код

Next.js здесь не тот, что в обучающих данных: смотри `web/AGENTS.md`. Перед PR: `npm run lint`, `npm run typecheck`,
тесты затронутых workspace, `npx prettier --check .` в корне (CI падает на `format:check`). Тесты api — на своей
одноразовой БД через `TEST_DATABASE_URL`.
