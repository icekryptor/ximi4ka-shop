# Аудит «детского» позиционирования, 22.10.2026

Снимок состояния кода, данных, живого сайта, картинок и семантического ядра на 22.10.2026, сделанный до решений Р1–Р3.
Рабочий документ — план `../2026-10-22-reposition-14-plus.md`. Где аудит расходится с планом, верен план. Например, фраза
«До 14 лет под присмотром взрослых» в аудите помечена как спорная, а по решению Р1 она входит в формулу возраста.

| Файл               | Что в нём                                                              |
| ------------------ | ---------------------------------------------------------------------- |
| `audit-code.md`    | код витрины и API, тесты запрещённых фраз, правила                     |
| `audit-data.md`    | `api/data`, сиды, черновики, SEO-план                                  |
| `audit-live.md`    | живой сайт: 207 страниц, фиды, llms.txt; источник каждого текста       |
| `audit-images.md`  | визуальная проверка картинок репозитория и живого сайта                |
| `audit-semcore.md` | доля детской семантики в ядре и нейтральные замены                     |
| `crawler/`         | скрипты обхода для повторной проверки после правок (только GET, пауза) |

Повторная проверка: `crawler/fetch.sh <список-url> <папка>` скачивает страницы, `crawler/extract.py` и `crawler/scan.py`
разбирают их (`python3 -I`), `crawler/report.py` собирает отчёт. Скачанное держать вне репозитория.
