# Аудит кода: позиционирование «для детей» → 14+

Дата: 22.10.2026. Ветка `claude/reposition-14-plus-certification-b6f7e7` (worktree `varioqub-setup-7bc530`), чистое
дерево, read-only. В репозитории ничего не менялось.

**Охват:** `web/app`, `web/components`, `web/lib`, `web/public` (текстовые файлы и картинки категорий и промо),
`web/middleware.ts`, `api/src` (кроме `api/data/*.json`), `shared/src`, `design-system/`, `docs/seo/`, `deploy/*.md`,
выборочно `docs/superpowers`. Исключены `node_modules`, `.next`, `dist`, lock-файлы, `api/data/*` (это отдельный аудит).

**Метод:** регистронезависимый поиск (rg) по русским и английским корням из брифа, затем ручное чтение контекста.
Отдельно выгружены все кириллические строки публичной витрины (906 строк без комментариев) и прочитаны целиком, чтобы
поймать косвенное позиционирование, которое не ловится по ключевым словам.

**Проверка на живом сайте.** Обычными GET-запросами, как посетитель, открыты `https://ximi4ka.ru/`, `/o-nas`, `/faq`,
`/cert`, `/blog`, `/product/bolshoi-nabor-dlya-oge`, `/llms.txt`, `/yml.xml`. Подтверждено: строки из пунктов, помеченных
«на проде ✔», сейчас видны на сайте. На прод-сервер и в прод-БД аудит не заходил.
