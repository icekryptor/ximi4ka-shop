# Админка: закреплённый сайдбар, таблица товаров с правкой на месте, фильтр по категории

Дата: 2026-11-13. Размер: небольшое изменение (короткий дизайн). Одобрено владельцем в чате.

## Зачем

Владелец правит цены, наличие, публикацию и порядок товаров пачкой. Сейчас на каждую правку — заход в полную карточку
товара. Левое меню уезжает при прокрутке длинного списка. Отобрать товары одной категории нельзя.

## Цели

1. Левое меню админки закреплено (`sticky`, высота экрана, своя прокрутка при нехватке высоты).
2. В таблице товаров правятся на месте: цена, старая цена, наличие, порядок сортировки, публикация.
3. Фильтр по категории над таблицей; работает вместе с поиском, сбрасывает пагинацию.

## Не цели

Назначение категорий товару, массовые действия над отмеченными строками, мобильный вид админки.

## Анти-цели

Правка одного поля не должна менять никакие другие поля товара (см. «Найденные дефекты»).

## Найденные дефекты, которые чиним попутно

- `UpdateProductSchema = CreateProductSchema.partial()`: в zod 4 `.default()` срабатывает и после `.partial()`, поэтому
  `PATCH {priceRub}` сбрасывал `longDescriptionBlocks`, `stockStatus`, `sortOrder`, `noindex`, `translations`. Схема
  обновления строится из базовой схемы без значений по умолчанию. Регрессионный тест.
- Админские страницы категорий запрашивают `?limit=200`, а `ListQuerySchema` категорий допускал максимум 100 → 400.
  Потолок поднят до 500.

## Подходы к сохранению правок

- **Сохранение ячейки сразу (выбрано).** Enter/потеря фокуса/смена select → PATCH одного поля; статус в строке;
  Esc откатывает. Меньше кликов, правки не теряются.
- Режим правки + «Сохранить всё». Защищает от случайных правок, но лишний шаг и потеря несохранённого при уходе.

## Устройство

- API `GET /api/admin/products?categoryId=<uuid>` — `EXISTS` по `product_category_links`, точное совпадение категории
  (как на витрине `/api/public/categories/:slug/products`, без подкатегорий).
- Публикация в таблице — через существующие `POST /:id/publish|unpublish`.
- Web: серверная страница грузит товары и категории, клиентский `ProductsTable` рендерит строки с редакторами;
  `ProductsCategoryFilter` пишет `?category=` в URL. Таблица с `overflow-x-auto`.

## Оставлено исполнителю

Вёрстка ячеек, тексты статусов, отступы подкатегорий в списке фильтра.
